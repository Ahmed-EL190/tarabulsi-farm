# الصيغ المالية وكيف تُنفَّذ (src/utils/finance.js, docs.js)
| الأصل في Excel | التنفيذ |
|---|---|
| Milk_Box!G الكمية = (يدوي) | الإجمالي = صباح + مساء إذا وُجد أحدهما، وإلا القيمة المخزنة |
| Milk_Box!K صافي ل.س `=IF(COUNTA(I:J)=0,"",I-J)` | `netSYP` = مقبوضات − مدفوعات، وفارغ إن لم يوجد أي منهما (الفراغ ≠ صفر) |
| Milk_Box!S صافي USD | `netUSD` بنفس القاعدة بشكل مستقل |
| Milk_Box_Dashboard صافي الصندوق | مقبوضات − مدفوعات لكل عملة؛ **مصروف الشريك (Q/R) لا يدخل الصندوق** |
| مصروف العلف/الدواء (J + Q) | مدفوعات + مصروف شريك بنفس العملة ويُحتسب مرة واحدة |
| Partner_Ledger!G `=G(prev)+E−F` | رصيد تراكمي لكل شريك = افتتاحي + إضافات − سداد فعلي |
| Land_Cost SUMIFS(partner, category, currency) | `landCostReport` مع تفصيل لكل خلية |
| لا جمع USD وSYP | `convert()` يرفض التحويل دون سعر وتاريخ |
## تصحيحات موثقة
- الإجمالي المفقود في 3 صفوف (125، 152، 155) يُحسب من صباح+مساء ويُسجَّل في الاستيراد كتحويل.
- 17 بند Partner-Depts منقولة أصلاً إلى Milk_Box: تُستورد كسجلات مرتبطة (`milkRef`) ولا تُحتسب مرتين.
